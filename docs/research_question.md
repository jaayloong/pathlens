# Research Question

**Can a context-aware ranking layer reduce unnecessary visual alerts while preserving recall of important environmental hazards compared with naive object reporting?**

## Working hypothesis
A ranking function combining semantic risk, relative distance, motion, path relevance, and detector confidence will improve relevance-based ranking metrics and reduce redundant alerts compared with detector-confidence-only reporting.

## Important limitation
PathLens is a research prototype. It is not validated as a mobility aid and must not be represented as a safety-certified navigation system.
